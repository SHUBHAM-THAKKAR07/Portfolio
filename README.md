# Shubham Thakkar — Fullstack Developer Portfolio

A clean, responsive developer portfolio showcasing projects, skills, and experience — built with HTML5, Tailwind CSS, and vanilla JavaScript.

## Tech Stack

- **HTML5** — Semantic markup
- **Tailwind CSS** — Utility-first styling with custom design tokens
- **Vanilla JavaScript** — Theme toggle, animations, dynamic project rendering

## Run Locally

```bash
# Start a local server
python -m http.server 3000
# Then open http://localhost:3000
```

Or use Node:

```bash
npx serve .
```
